NFRUX is one file, nvngx_dlssg.dll (nfrux.ini, the options, is optional and goes in the same folder). Copy it under the name the route asks for; delete that copy to uninstall. Nothing is registered, and nothing else
is written unless a log is asked for (a crash marker lives in %LOCALAPPDATA%\NFRUX for a game's first frames, and is removed after; kept when two starts failed).

OptiScaler 0.9.5 (2x): beside OptiScaler as dlssg_to_fsr3_amd_is_better.dll; in OptiScaler.ini FGInput=nukems, FGOutput=nukems.
OptiScaler builds with FGNvngxReplacement: OptiScaler\custom\NFRUX\dlssg\nvngx_dlssg.dll; FGInput=nvngxfg, FGNvngxReplacement=NFRUX (2x to 6x). If a D3D12 game crashes at start, try LogLevel=0 and LogToFile=true in OptiScaler.ini.
Games with Streamline, no OptiScaler: beside the game's .exe as dbghelp.dll, or version.dll if the game does not load that one.
Use one route only. Not for games with anti-cheat.
To report a problem: Log=1 in nfrux.ini writes nfrux.log beside the DLL; Network=scalar takes the plainest network path.
